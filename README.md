Pharmacovigilance ICSR Case Processing Project

A comprehensive academic simulation project demonstrating the end-to-end workflow of Individual Case Safety Report (ICSR) processing within pharmacovigilance and regulatory affairs.

Project Overview:
This project simulates the processing, evaluation, and quality control of 20 spontaneous adverse event source reports. It bridges unstructured source documentation with structured data tracking, adhering to standard pharmacovigilance workflows from intake to regulatory assessment.

Project Structure
1. Source_ reports.docx: Contains 20 fictional patient/physician adverse event source reports (PV001 to PV020) detailing suspect drugs, indications, adverse event descriptions, timelines, and outcomes.
2. Pharmacovigilance_ICSR_Case_Processing_Project.xlsx: An advanced multi-tab Excel workbook tracking the lifecycle of each case across ten distinct operational stages.

Workbook Architecture (.xlsx Tabs)
1. Case Intake: Logs core case identifiers, patient demographics, suspect medications, indications, reported adverse events, onset dates, and outcomes.
2. ICSR Validity: Evaluates the four core criteria for a valid ICSR (Identifiable Patient, Identifiable Reporter, Suspected Drug, Adverse Event).
3. Seriousness Assessment: Classifies cases based on regulatory seriousness criteria (e.g., hospitalization, medically important conditions).
4. Expectedness (RSI): Evaluates adverse event expectedness against reference safety information (RSI).
5. MedDRA Coding: Maps reported terms to Lower Level Terms (LLT), Preferred Terms (PT), and System Organ Classes (SOC).
6. Causality Assessment: Performs WHO-UMC causality categorization (e.g., Possible) with structured justifications.
7. Follow-up Assessment: Identifies missing data points and formulates targeted follow-up questions for reporters.
8. Regulatory Assessment: Determines expedited (15-day) vs. routine (90-day) reporting timelines based on case seriousness and expectedness.
9. QC Assessment: Tracks verification status across all case attributes prior to final sign-off.
10. DASHBOARD: Dynamic KPI summary dashboard featuring total case counts, validity metrics, seriousness breakdowns, and outcome distributions.

Key Highlights & Industry Compliance Awareness
* Standard Operating Procedures (SOPs): Aligns with standard pharmacovigilance triage principles.
* Transparent Disclaimers: Includes appropriate academic simulation disclaimers regarding official MedDRA dictionary access constraints, RSI version controls, and reporter identifiability requirements.
* Dynamic Excel Modeling: Utilizes automated Excel functions (COUNTIF, COUNTA) to drive summary dashboards and real-time tracking metrics.
